# Finance Tracker Web App 
Team 4 SDEV265-109 Ivy Tech Summer 2024

## Introduction
The Finance Tracker web app is designed to help users manage their personal finances by tracking transactions, incomes, and expenses. The app includes features such as viewing all transactions, categorizing them, and visualizing financial data through charts and summaries.
**Note:** This project is still in the development phase and currently lacks user authentication and authorization features. As a result, all user-related functionalities, such as login and signup, are not yet implemented.

## Features
- Dashboard displaying a summary of all transactions with charts
- View all transactions in reverse chronological order
- Add new incomes and expenses
- View only incomes or only expenses with forms for adding new transactions

## Prerequisites
To run this project locally, you need to have the following software installed:
- Node.js (version X.X.X)
- MongoDB (local instance or MongoDB Atlas)

## Installation and Setup

### 1. Clone the Repository
First, clone the repository to your local machine using the following command:
`bash`
`git clone https://github.com/dwkolb/team4-project-sdev265-10p.git`
`cd team4-project-sdev265-10p`

### 2. Install Backend Dependencies
Navigate to the backend directory and install the necessary dependencies:
`cd backend`
`npm install`

### 3. Install Frontend Dependencies
Open a new terminal, navigate to the frontend directory, and install the necessary dependencies:
`cd frontend`
`npm install`

### 4. Run the Application
You need to start both the backend and the frontend servers. Open two separate terminal windows or tabs for this purpose.

Terminal 1: Start the Backend Server
Navigate to the backend directory and start the server:
`cd backend`
`npm start`
The backend server should be running on http://localhost:5000.

Terminal 2: Start the Frontend Server
Navigate to the frontend directory and start the server:
`cd frontend`
`npm start`
The frontend server should be running on http://localhost:3000.

### 5. Accessing the Application
A web browser should open up automatically
If not: Open your web browser and go to http://localhost:3000 to access the Finance Tracker web app.

## Usage
Once the app is running, you can navigate through the following sections:

Dashboard: View a summary of all transactions with charts and the most recent transactions.
View Transactions: See a list of all transactions in reverse chronological order.
Incomes: View all income transactions and add new incomes.
Expenses: View all expense transactions and add new expenses.
